MindGit Agent — installatie op een andere server
=================================================

Er zijn twee manieren: de interactieve installer (aanbevolen) of handmatig.
Je hebt Node.js 18+ en Git nodig. De installer regelt de rest.

LET OP: het bestand `.env` bevat je node-key en is per server verschillend.
De installer maakt hem voor je aan; commit of deel hem nooit.


Snelste manier — alleen setup.js
--------------------------------
Zet één bestand op de server en start het:

    curl -fsSL https://git.minddev.nl/agent/setup.js -o setup.js
    node setup.js

De installer vraagt:
  1. Waar de agent geïnstalleerd moet worden
  2. Waar hij vandaan komt (GitHub of de MindGit-coordinator)
  3. De coordinator-URL en je node-key
  4. Of auto-update aan moet
  5. Of hij via PM2 of systemd moet starten

Daarna kun je hetzelfde script opnieuw starten voor beheer:
bijwerken, starten/stoppen, doctor, logs, .env aanpassen en verwijderen.

Niet-interactief:

    node setup.js --yes --dir /opt/mindgit-agent \
      --coordinator=https://git.minddev.nl \
      --node-key=JOUW_NODE_KEY --pm2

Opties: `node setup.js --help`.


Stap 1 — Maak een node aan in MindGit
-------------------------------------
Dashboard: Nodes -> Node toevoegen -> naam + platform -> key kopieren.

Of via de CLI (vanaf de machine met toegang tot de coordinator):

    ./scripts/new-node.sh --server https://git.minddev.nl --user admin --name "mijn-server"

Je krijgt een NODE_KEY van 64 tekens. Bewaar hem goed.


Stap 2 — Installeren (handmatig)
--------------------------------
    unzip mindgit-agent-<versie>.zip
    cd mindgit-agent
    cp .env.example .env
    # bewerk .env: zet COORDINATOR_URL en NODE_KEY

Voorbeeld:

    COORDINATOR_URL=https://git.minddev.nl
    NODE_KEY=jouw-64-tekens-key

Optioneel: BROWSE_ROOTS=/home/user/projecten,/srv/repos


Stap 3 — Controleren en starten
-------------------------------
    node index.js doctor     # moet allemaal [ OK ] geven
    node index.js            # agent starten

Blijvend draaien? Kies een supervisor:

  PM2:
    pm2 start index.js --name MindGitAgent
    pm2 save

  systemd (voorbeeld staat in deploy/mindgit-agent.service):
    sudo cp deploy/mindgit-agent.service /etc/systemd/system/
    sudo systemctl daemon-reload
    sudo systemctl enable --now mindgit-agent

  Of gebruik het installatiescript (zet alles automatisch op):
    sudo bash scripts/install-linux.sh --coordinator=https://git.minddev.nl --node-key=JOUW_KEY


Controleren
-----------
In het dashboard staat de node onder Nodes op Online. Wijs daarna repositories
toe via Nodes -> jouw node -> Repository toewijzen.


Beheer
------
    node setup.js            # interactief beheer-menu
    node index.js doctor
    node index.js config
    node index.js --version
    pm2 logs MindGitAgent


Beveiliging
-----------
- De node-key is geheim. Bewaar .env veilig (chmod 600) en commit hem nooit.
- De agent maakt alleen UITGAANDE verbindingen; je hoeft geen poort te openen.
- De mapbrowser is beperkt tot BROWSE_ROOTS.
- Self-update staat standaard uit (UPDATE_ENABLED=false). Zet dit alleen aan als
  je zelf de update-repo beheert; de agent voert die code namelijk uit.
